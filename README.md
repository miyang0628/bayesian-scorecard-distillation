# Bayesian Scorecard Distillation

Reproducibility code for the manuscript

> **Distilling a High-Capacity Teacher into a Bayesian Additive Scorecard, with Evolutionary Structure Search**
> *Anonymous author(s). Submitted to a peer-reviewed statistics journal — under review.*

This repository distils a high-capacity gradient-boosting teacher into a **transparent, hand-computable additive scorecard** whose per-bin scores carry a **posterior distribution**, and studies—across six tabular domains—what interpretability costs, whether the teacher's calibration transfers, how integer quantization propagates into credit grades, and how an evolutionary search trades complexity against performance.

The study is fully self-contained: every notebook is a single, self-contained cell and regenerates all figures and tables under `results/`.

---

## Method in brief

- **Teacher.** A high-capacity, interaction-capable gradient-boosting ensemble (LightGBM) supplies calibrated class probabilities. The teacher never enters the deployed artefact.
- **Lossless reduction (Map A).** A depth-one (stump) ensemble is *already* an additive scorecard; the per-feature step functions are recovered exactly from the model's additive contributions (verified to floating-point precision).
- **Generalized distillation posterior.** Score distillation is cast as *generalized Bayesian updating*: the student minimises a dual-target loss that convex-combines the Bernoulli log-loss against the label with the cross-entropy against the teacher, under structured priors (random-walk smoothness, teacher-informed centring, ridge/shrinkage). The posterior is obtained by a Laplace approximation (MAP + inverse-Hessian), justified by a Bernstein–von Mises argument.
- **Loss dualization.** The *approximation* loss of the constrained additive class and the *quantization* loss of integerization are measured on separate axes and never summed.
- **Quantization as a Bayes decision.** Points-to-double-the-odds integerization is evaluated at three levels (probability, ranking, grade), with grade stability reported as a posterior quantity.
- **Evolutionary structure search.** A compact NSGA-II searches binning structures on a Pareto surface of (discrimination, complexity, grade stability).
- **Calibration-transfer gates.** Content-versus-softness and rank-preserving-miscalibration controls isolate genuine calibration transfer from mere label smoothing.

## Repository layout

```
.
├── data/                 # raw datasets (not tracked); processed cache written here
├── analysis/             # review-round scripts: UQ, DeLong/TOST, PG-Gibbs, SBC, horseshoe
├── notebooks/            # one self-contained cell per notebook, English comments
│   ├── 00_data_overview.ipynb
│   ├── 01_teacher_and_reduction.ipynb
│   ├── 02_bayesian_scorecard.ipynb
│   ├── 03_calibration_transfer.ipynb
│   ├── 04_quantization.ipynb
│   ├── 05_evolutionary_search.ipynb
│   └── 06_decision_impact_fairness.ipynb
└── results/
    ├── figures/          # grayscale, caption-free, 600 dpi, PNG + PDF
    │                     #   00–06 from notebooks; A1–A3 from analysis scripts
    └── tables/           # CSV + LaTeX (00–06); out_*.csv from analysis scripts
```

The `results/` directory ships pre-populated so the figures and tables can be
inspected without re-running; everything is regenerated by the notebooks and the
`analysis/` scripts. The six raw datasets are not tracked (see *Data* below); add
them to `data/` to re-run.

## Data

Six public tabular datasets spanning distinct domains are used. They are **not redistributed** here; place the files in `data/` under the names expected by the notebooks:

| Key | Domain | File expected in `data/` | Target |
|-----|--------|--------------------------|--------|
| `telco` | Telecom churn | `telco_churn.csv` | churn |
| `adult` | Income | `adult.parquet` | high income |
| `corporate` | Corporate rating | `corporate_rating.csv` | investment grade |
| `creditrisk` | Consumer loan | `credit_risk.csv` | default |
| `gmsc` | Retail credit | `gmsc.parquet` | serious delinquency |
| `taiwan` | Card default | `taiwan.parquet` | default |

All targets are binarised; injected/duplicate columns are dropped to avoid leakage, and canonical demographic columns are retained only as protected attributes for the fairness audit.

## Reproducing the results

```bash
pip install -r requirements.txt
# then run notebooks 00 → 06 in order, e.g.:
jupyter nbconvert --to notebook --execute --inplace notebooks/*.ipynb
```

All outputs are written to `results/figures/` (PNG + PDF, 600 dpi, grayscale) and `results/tables/` (CSV + LaTeX). A global random seed fixes the pipeline; teacher probabilities are cached under `data/processed/` on first run. No filesystem paths are printed, to keep execution logs anonymous.

## Notebooks

| Notebook | What it produces |
|----------|------------------|
| `00_data_overview` | dataset sizes, base rates, feature mix; base-rate figure |
| `01_teacher_and_reduction` | teacher AUC/ECE/reliability; exact additive-reduction residuals; reliability diagrams; step functions |
| `02_bayesian_scorecard` | baseline vs distilled scorecard; posterior credible bands on per-bin scores |
| `03_calibration_transfer` | content-vs-softness and miscalibration gates across domains |
| `04_quantization` | three-level quantization loss; grade-migration curves |
| `05_evolutionary_search` | NSGA-II Pareto fronts; knee solutions |
| `06_decision_impact_fairness` | approved-group default rate by cutoff; gender fairness (AIR, approval gap) |
